基准：WCAG 2.2 A / AA  
适用范围：公开排盘、结果页、记录、设置、登录和管理后台

## 自动化门禁

- [x] TypeScript 类型检查
- [x] ESLint（允许仓库既有 warning，不允许 error）
- [x] Next.js 生产构建
- [x] Playwright + axe：320 × 900、412 × 823、1440 × 900
- [x] Lighthouse CI：六个公开入口的无障碍得分必须为 100
- [x] 公开路由无页面级横向溢出
- [x] Dialog 打开、焦点进入、Escape 关闭和焦点恢复
- [x] 八字、紫微、六爻结果页结构与自动对比度检查
- [x] `prefers-reduced-motion: reduce` 静态回退

CI 工作流：`.github/workflows/accessibility.yml`。任何前端 Pull Request 都必须通过上述检查；Playwright 失败时保留截图与 trace，Lighthouse 报告作为构建产物上传。

## 回滚边界

- Dialog 回归：可暂时回滚 `AccessibleDialog` 迁移，但不得恢复无语义、无焦点约束的旧弹层后发布。
- 颜色或字号造成布局问题：优先调整局部布局，不得回滚到低于 AA 的颜色或 6–10px 常规正文。
- 自动化误报：记录具体规则与 DOM 证据；不得直接全局禁用 axe 规则。
