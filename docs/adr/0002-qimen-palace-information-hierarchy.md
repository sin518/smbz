# ADR 0002：奇门九宫采用分层展示与天盘长生

- 状态：已接受
- 日期：2026-07-26

## 背景

原九宫将天盘干、地盘干、九星、八门、八神和五行说明以近似权重展示，空亡只使用无法区分日空与时空的符号，中宫寄干也可能被隐藏。页面同时缺少年命、日干和时干的落宫坐标。加入十二长生后，如果继续平铺字段，移动端宫格会进一步过载。

## 决策

1. 宫格以天盘干和八门为一级信息，九星和八神为二级信息，地盘干、五行和天盘长生为三级信息。
2. 天盘干和地盘干显式标注“天”“地”；寄宫产生多个天盘干时完整展示。
3. 年命、日干和时干由 Core 统一计算天盘定位宫，页面分别使用“命”“日”“时”标记。甲干按对应六甲遁干定位。
4. 日空、时空、驿马和入墓使用文字状态；格局在九宫下方集中汇总。
5. 十二长生只针对天盘干计算，采用阳干顺行、阴干逆行。四隅宫保留两个地支结果，多个天盘干分别计算。
6. Core、规范 JSON 和规范文本保留十二长生全称；宫格为了移动端密度使用单字缩写。
7. 九宫使用独立语义主题变量，完整响应浅色、深色和跟随系统主题；五行颜色必须与实际五行一致，并且不能作为唯一信息载体。

## 影响

- 优点：专业盘面信息完整，视觉主次清晰；年命、日干、时干可直接定位；页面与 AI 使用同一套确定性长生数据。
- 代价：Core 输出契约增加宫位地支、天盘长生和日时干坐标字段，九宫高度略有增加。
- 风险控制：新增字段保持向后兼容；十二长生使用中性样式，提示词禁止将单个“死、墓、绝”作为决定性结论。
