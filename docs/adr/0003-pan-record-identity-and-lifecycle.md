# ADR 0003：盘局记录采用稳定业务身份与统一生命周期

- 状态：已接受
- 日期：2026-07-26

## 背景

现有记录以设备随机生成的 `localId` 作为同步幂等键，只能防止同一设备重试，无法识别电脑和手机创建的同一盘局。结果页还存在打开已有记录时再次保存的行为，删除后的离线副本也可能重新上传。盘局记录需要独立于设备、浏览器和录入表示的稳定身份。

## 决策

1. 每条盘局记录使用带版本的稳定业务身份 `recordKey`；`localId` 只表示设备写入，不参与判断是否为同一记录。前后端遵循同一规范化规则，后端负责校验并以用户、占术类型和 `recordKey` 保证唯一。
2. 八字和紫微按求测主体姓名及规范化出生输入识别；等价公历/农历和等价地点表示属于同一输入，真太阳时设置不同属于不同输入。奇门和大六壬按规范化占事、起局时间、出生年及配置识别。六爻按一次已完成起卦的稳定身份识别，分别完成的两次起卦始终是两条记录。
3. 打开已有记录是严格只读行为，不保存、不改变时间、同步状态或排序。用户明确重新提交相同身份时更新原记录，保留最早 `createdAt`，刷新内容和 `updatedAt`，列表按最近更新时间排序。
4. 历史重复记录自动合并为一条主记录，保留最早创建时间以及最新内容和更新时间，并让各设备 ID 映射到主记录。不支持同时存在的完全相同活动副本。
5. 删除是跨设备状态，旧离线副本不得自动复活记录。删除后的明确用户提交可以开始同一业务身份的新生命周期。
6. 排盘计算版本不属于记录身份；同一输入的新版计算结果更新原记录。同步冲突时旧计算版本不得覆盖新版本。

## 影响

- 优点：从数据库写入到列表展示共享同一记录身份，多设备和并发重试不会产生重复；浏览、更新和删除语义可测试。
- 代价：需要新增身份版本、生命周期版本、唯一约束和历史合并迁移，并为五类占术维护各自的规范化规则。
- 风险控制：迁移先生成预览和备份；身份规则使用跨语言契约测试；旧客户端在兼容期仍可按 `localId` 同步，但不能覆盖已有稳定身份记录。
