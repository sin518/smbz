# ADR 0004：本机盘局记录迁移到账号隔离的 IndexedDB

- 状态：已接受
- 日期：2026-07-26

## 背景

现有盘局记录保存在未按账号分区的全局 `localStorage`，完整盘局 JSON 会受到容量和同步读写限制；同一浏览器切换账号时还可能误展示或误上传前一账号的数据。固定数量截断会静默丢弃未同步记录，云端读取错误也会被当成空列表。

## 决策

1. 完整盘局记录、记录摘要、同步状态、生命周期版本和删除状态统一迁移到带结构版本的 IndexedDB；`localStorage` 只保留主题和最后输入等小型偏好。
2. IndexedDB 按用户 ID 隔离账号空间，游客使用独立空间。游客记录只能在用户明确确认后导入账号；旧版无法确认归属的全局记录进入待认领空间，不展示也不自动上传。
3. 普通退出隐藏但保留当前账号的本机数据，并提供“退出并清除此设备数据”。任何其他账号和游客都不能读取该空间。
4. 本机保存成功后，登录状态立即后台同步；网络失败保留待同步状态，联网事件和定时任务只负责重试。未同步记录不得因数量或容量限制静默删除。
5. 多端首次同步只下载记录摘要；完整盘局在打开时按需下载并缓存，用户可以明确下载全部供离线使用。普通缓存可按容量策略淘汰，用户固定的离线副本不得静默清理。
6. 云端读取失败时展示最后缓存和本机记录，并明确标记数据可能不是最新，不得把请求失败解释为云端没有记录。

## 影响

- 优点：支持事务、账号隔离、结构迁移和可控缓存，降低同步阻塞、隐私串号和静默丢失风险。
- 代价：所有记录读写接口需要异步化，并增加旧存储迁移、游客认领、缓存清理和失败恢复流程。
- 风险控制：采用分阶段迁移，先复制并校验数量和内容，再切换读取来源；旧键保留一个兼容周期，确认迁移成功后才清理。
