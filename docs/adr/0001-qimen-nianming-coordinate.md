# ADR 0001：奇门年命采用公历出生年份与天盘定位

- 状态：已接受
- 日期：2026-07-26

## 背景

奇门排盘需要区分求测主体、页面操作者和事项相关方。年命属于求测主体，是长期个人坐标；日干表示起局当下的自身状态，时干表示所问之事。仅记录一个年命天干不足以稳定定位甲命，也无法让页面、规范输出和 AI 提示词共享同一计算结果。

## 决策

1. 页面要求填写求测主体的公历出生年份，只收集年份，不收集月份和日期。
2. 出生年干支直接按公历年份换算，不校正立春边界。因此立春前后的用户可能与四柱年柱口径不同，界面与输出不得把它称为精确四柱年柱。
3. 年命取出生年天干。非甲命直接以该天干为定位干；甲命按完整出生年干支映射六甲遁干：
   - 甲子遁戊
   - 甲戌遁己
   - 甲申遁庚
   - 甲午遁辛
   - 甲辰遁壬
   - 甲寅遁癸
4. 年命宫以定位干在天盘所在宫为准。中宫寄宫产生多个天盘干时，所有天盘干都参与定位；地盘同干只作背景参考。
5. Core 统一输出出生年干支、年命、定位干和天盘年命宫。页面、JSON、文本和 AI 提示词复用这些确定性结果，不在展示层或大模型中重复计算。
6. 旧记录缺少出生年份时仍可解读基础盘，但必须明确年命数据缺失，并省略年命结论。

## 影响

- 优点：只需一个低摩擦输入即可得到可复现的年命坐标；各消费端口径一致；甲命和中宫寄宫边界可测试。
- 代价：不处理立春边界，精度低于完整出生日期方案。
- 风险控制：页面明确字段属于求测主体；AI 提示词不得让年命单独推翻日干、时干和事项用神形成的主要结论。
